# AetherClick — Liquid Glass Auto Clicker & Automation Studio
### Designed & Developed by Hammad Designz

A next-generation precision Auto Clicker engineered with an authentic **Apple Liquid Glass** user interface, microsecond timing loops, and comprehensive automation features. Available as a standalone **Windows Desktop App** and as a **Google Chrome Extension (Manifest V3)**.

---

## 🌟 Key Features

- **Apple Liquid Glass UI**: Translucent obsidian dark surfaces, frosted glass blur, tactile micro-interactions, and neon status badges.
- **Microsecond Precision Engine**: Zero-lag clicking from 1ms up to 1,000+ CPS with multi-threaded high-performance loops.
- **Random Jitter Mode**: Built-in humanization and anti-cheat avoidance with randomized millisecond intervals.
- **System Tray Background Mode**: Minimizes cleanly to the Windows System Tray with native Action Center notifications.
- **In-Browser Chrome Extension**: Auto-click directly in Google Chrome / Brave / Edge with coordinate and target element pickers.
- **Global Hotkeys**: Quick start and stop using `F6` (Desktop) or `Ctrl + Shift + X` (Chrome Extension).

---

## 📥 Download & Installation

### Windows Desktop App
Download the official setup installer from the [Releases](https://github.com/HafizHammad14/AetherClick/releases) tab:
- **`AetherClick-Installer.exe`**: One-click setup installer with desktop shortcuts and background tray integration.

### Chrome Extension (Manifest V3)
Download **`AetherClick-Chrome-Extension.zip`** from Releases:
1. Extract the zip folder.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top-right).
4. Click **Load unpacked** and select the extracted folder.
