## 🌟 Overview
**AetherClick Chrome Extension** brings the desktop auto-clicker experience directly into Google Chrome, Microsoft Edge, Brave, and Opera. Engineered with an Apple Liquid Glass user interface, it provides lightning-fast in-browser automation, live CPS counters, and target element selection.

---

## 🚀 How to Install in Google Chrome / Brave / Edge

### Step 1: Open Extension Management
1. Open Google Chrome.
2. Navigate to: `chrome://extensions/` (or click Menu `⋮` -> **Extensions** -> **Manage Extensions**).

### Step 2: Enable Developer Mode
1. In the top-right corner of the Extensions page, toggle **Developer mode** to **ON**.

### Step 3: Load the Extension
1. Click the **Load unpacked** button in the top-left corner.
2. Select the folder:
   `c:\Users\Hammad Designz\Downloads\Autoclicker-1\AetherClick-Chrome-Extension`
3. Click **Select Folder**.

### Step 4: Pin for Easy Access
1. Click the **Extensions Puzzle Icon** in Chrome's top toolbar.
2. Find **AetherClick** and click the **Pin** icon.

## 🎯 Key Features
- **Apple Liquid Glass UI**: Dark obsidian frosted glass design with dynamic neon emerald and cyan accents.
- **Microsecond Precision**: Interval control down to 1ms (up to 1,000 CPS in-browser).
- **Random Jitter Mode**: Evade bot detection on web games and forms with randomized click timing.
- **Multiple Target Modes**:
  - **Follow Live Cursor**: Auto-clicks wherever your mouse points.
  - **Fixed Coordinates**: Click exact (X, Y) pixel locations on any webpage.
  - **Pick Target Element**: Click any button, link, or input with automatic selector resolution (`#submit-btn`, etc.).
- **On-Screen Floating HUD**: Displays real-time CPS, total click count, and a quick Stop button directly on web pages.
- **Repeat Limits**: Infinite clicking or auto-stop after a set number of clicks.
- **Zero Inline Scripting**: 100% compliant with Chrome Manifest V3 Content Security Policy (CSP).
